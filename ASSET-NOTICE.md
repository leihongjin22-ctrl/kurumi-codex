The character illustrations and themed graphics in `assets/` are project demo artwork. The project code license does not grant rights to third-party characters, names, trademarks, or franchise material, and does not indicate an official collaboration. Replace these assets with your own licensed artwork when preparing your own distribution.

The original vector clock icon `assets/plugin-icon.svg` is covered by the project code license. Asset filenames are kept stable so the theme can be replaced without changing client logic.
